### 外部数据库用例的环境策略

- CI 通过环境变量 `XCode_mysql` / `XCode_pgsql` / `XCode_sqlserver` 注入连接串；未注入时由工作流把对应测试组排除在运行范围外（见 `.github/workflows/test.yml`）。
- PostgreSQL 真库用例使用 `[PostgreSQLFact]`：本地未注入 `XCode_pgsql` 且按连接串的 Server/Port 探测不到服务时自动跳过，避免缺少数据库的开发机出现红灯；CI 注入连接串后始终执行，不用探测结果掩盖真实失败。

### 新增数据库的 CI 真库覆盖（db-compat）

主测试任务只保留 MySQL / PostgreSQL / SQLServer 三库全量；其余数据库由独立工作流 `db-compat.yml` 按库并行拉起容器跑对应测试组。

- **统一探针**：`[LiveDatabaseFact("<key>", "<configName>", 端口)]`。环境变量 `XCode_<key>` 存在时直接执行；否则读 `Config/<configName>.config` 探测 TCP，不通即跳过。
- **连接串解析**：`LiveDatabase.Resolve(key, configName, defaultConnStr)`，顺序为环境变量 → 配置文件 → 默认值（缺失时写出模板）。
- **首期 advisory**：`continue-on-error: true`，失败只告警不阻断；逐库稳定后再关闭。
- **触发**：master 推送、tag 发布与手动触发。
