# 数据库支持矩阵

> 版本：v12.3 | 日期：2026-11-21

本文档说明 XCode 对各数据库引擎的支持现状与落地成本。结论先行：**「有 ADO.NET 驱动」只是入场券，不等于 XCode 能直接支持**。

XCode 的提供者契约（`IDatabase` / `DbBase` / `DbMetaData`）还要求：

| 契约 | 说明 |
|------|------|
| `DbProviderFactory` | 能创建连接、命令、参数；部分驱动（如 MonetDB）需要反射工厂适配 |
| SQL 方言 | 标识符引用、分页、布尔/时间字面量、字符串拼接、关键字表 |
| 元数据 | `GetSchema` 或 `information_schema` 查询，否则反向工程与自动迁移不可用 |
| 事务 | 批量、迁移、`EntityTransaction` 依赖 |
| 自增/主键/索引 | XCode 实体模型默认假设存在自增主键 |
| 写入能力 | 增删改是否有意义，取决于引擎本身 |

## 六、Presto / Trino 能力边界

| 能力 | 支持情况 |
|------|---------|
| 查询 / 聚合 / 分页 | ✅ `OFFSET ... LIMIT ...` |
| 实体查询、反向工程 | ✅ 走 `information_schema.tables/columns`；字段按表名分批查询以兼容老版 Hive Metastore，无法解析的坏表跳过；元数据查询不做无 limit 的排序，兼容 strict mode |
| Insert / Update / Delete | ⚠️ 取决于连接器，失败由服务端报错；实体主键不可声明为自增，否则抛出明确异常 |
| 事务 | ❌ 驱动与服务端均不支持 |
| 自增主键 | ❌ 无；请使用业务主键（Guid/雪花），或显式提供主键值并设置 `AllowInsertIdentity` |
| 自动建表 / 结构迁移 | ❌ 强制 `Migration=Off`，DDL 入口抛 `NotSupportedException` |
| 批量操作 | ❌ 不含 `DatabaseCapability.Bulk*` |
| 参数化 | ✅ 默认开启；`NewLife.Presto` 在客户端把 `@name` 绑定为安全字面量，跳过字符串与注释 |
| 复杂类型（array/map/row/json） | ✅ 一层强类型数组默认开启：映射为 `String[]`/`Int16[]`/`Int32[]`/`Int64[]`/`Double[]`/`Decimal[]`/`Boolean[]`，自动补 `ComplexTypes=Structured`，支持 `ArrayContains`、数组读写（`CAST(ARRAY[...] AS array(type))`）；`Arrays=Off` 或 `ComplexTypes=String` 退回 JSON 字符串。map/row/不支持的元素继续为 JSON 字符串；DDL 仍不接管 |
| 类型参数 | ✅ 从 `data_type` 解析 `varchar(n)`/`char(n)`/`decimal(p,s)`；无长度 `varchar`（含 Hive `string`）按长文本 `Length=-1` 处理 |
| 字段注释 | ✅ `information_schema.columns` 不含注释，反向工程逐表 `DESCRIBE` 一次拿回类型、注释与分区标记；元数据损坏的表直接跳过（点名取表时才回退 `information_schema.columns`） |
| 表注释 | ❌ 本环境 `SHOW CREATE TABLE` 无权限，表级注释取不到 |
| 主键约定 | ⚠️ Hive 不返回约束。反向工程把首个物理名 `id` 的列标为主键；没有 `id` 的表不臆造主键 |
| 分区列 | ✅ 全部表都会 `DESCRIBE`，按 `Extra=partition key` 精确识别分区列（不依赖列名约定），自动生成普通索引（如 `IX_PExample_ds`），实体可按分区查询 |
| 分区表查询 | ⚠️ 无分区条件时服务端直接拒绝扫描（如 `default.p_example`），XCode 不感知分区，查询必须自带分区过滤 |

### 连接字符串

**Presto**

```
Host=localhost;Port=8080;Catalog=hive;Schema=default;User=xxx;Password=xxx
```

**Trino**

```
Host=localhost;Port=8080;Catalog=hive;Schema=default;User=xxx;Password=xxx
# 认证模式：None / Basic / Jwt / OAuth2，缺省按 AccessToken、Password 推断
Auth=Basic;User=xxx;Password=xxx
Auth=Jwt;AccessToken=xxx
Auth=OAuth2;TokenEndpoint=xxx;ClientId=xxx;ClientSecret=xxx
```

> `Database` 会被映射为 `Catalog`，`Owner` 会被映射为 `Schema`，兼容 XCode 的习惯写法。
> XCode 在未显式指定时补 `UseSsl=false` 与 `Port=8080`；Trino 自动加 `Protocol=Trino`。
> 旧写法 `EnableSSL`/`TrinoHeaders` 会被归一化为 `UseSsl`/`Protocol`。
> `FastCount` 是 XCode 行为开关，会在建连前从连接串移除，不会下发给驱动。

### 驱动说明

- 统一使用 `NewLife.Presto`：纯 C# 实现，只依赖 `NewLife.Core`，覆盖 `net45`~`net11`，Presto 与 Trino 共用同一套协议实现，仅切换 `X-Presto-*` / `X-Trino-*` 请求头。
- 驱动自带 `DbProviderFactory`、`DataAdapter`、`SchemaTable` 与参数绑定器，XCode 不再需要反射工厂或字符串替换补丁。

### 反向工程到实体模型

- **无长度字符串**：Hive `string` 对应 `varchar` 无长度，模型输出 `Length="-1"`（长文本）。这是源表事实，不建议伪造长度；需要定长约束时在 Model.xml 手工指定。
- **物理名大小写**：表 `aaa` 的逻辑名会规范为 `Aaa`，导出 Model.xml 时用 `NameFormats.Exact` 才会保留 `TableName="aaa"`，否则按名称查询时大小写可能不符。
- **非法标识符**：形如 `custom-1` 的列名无法生成 C# 属性，反向工程后需在模型里改逻辑名并保留 `ColumnName`。
- **主键**：Hive 不返回约束，反向工程把首个物理名 `id` 的列标为主键；其它表需在 Model.xml 手工指定。
- **分区索引**：`DESCRIBE` 的 `Extra=partition key` 标记出分区列，不论列名（`ds`/`dt` 或其它）都自动生成普通索引（如 `IX_PExample_ds`），实体生成后可直接按分区过滤，避免全表扫描被拒。
- **注释**：一个 `DESCRIBE` 同时带回类型、注释与分区标记，反向工程按表逐个并发 `DESCRIBE`（8 线程），元数据损坏的表直接跳过。实测本机 395 张表约 17 秒、4596 张表约 143 秒，比整库扫描 `information_schema.columns` 快 2~4 倍。

## 七、Firebird 能力边界

> 要求 Firebird 3.0+（IDENTITY 列与 `INSERT ... RETURNING`）。

| 能力 | 支持情况 |
|------|---------|
| 查询 / 分页 | ✅ `ROWS m TO n` |
| Insert / Update / Delete | ✅ |

| 事务 | ✅ |
| 自动建表 / 结构迁移 | ✅ 支持 Create Table / Add Column / 索引 |

```
Database=../data/test.fdb;DataSource=localhost;User=SYSDBA;Password=masterkey
```

## 八之二、时序数据库能力边界

### OpenTSDB

| 能力 | 支持情况 |
|------|---------|
| 写入 | ✅ `POST /api/put` JSON 数据点；同一 metric+timestamp+tags 覆盖旧值 |
| 查询 | ✅ `GET/POST /api/query`；结果展开为 `time/metric/tags/value` 行 |
| 实体写入 | ✅ 单数值列映射为 metric；多数值列拆成 `表名.字段名` 子指标；主键/Master/字符串列映射为 tags |
| 更新 / 删除 | ❌ 无接口；请通过 HBase 工具处理历史数据 |
| 事务 / DDL / 自增 | ❌ |
| 元数据 | ⚠️ 仅 `/api/suggest?type=metrics` 指标名列表 |
| 前置条件 | 新建指标需服务端开启 `tsd.core.auto_create_metrics`；metric 与 tag 值不能含空白字符 |

```
Server=http://localhost:4242;Timeout=30
```

### Apache IoTDB

| 能力 | 支持情况 |
|------|---------|
| 查询 / 非查询 SQL | ✅ `POST /rest/v2/query` 与 `/rest/v2/nonQuery`，SQL 原样转发 |
| 实体 ORM | ❌ 能力门禁拒绝；请使用 DAL 原生 SQL |
| 事务 / 自增 | ❌ |
| 元数据 | ⚠️ 仅 database 级（`SHOW DATABASES`） |
| 行数限制 | 服务端默认限制可能截断结果，可设置连接串 `RowLimit` |

```

```

### Prometheus / VictoriaMetrics

| 能力 | 支持情况 |
|------|---------|
| 即时查询 | ✅ `GET /api/v1/query`，CommandText 为 PromQL |
| 范围查询 | ✅ `GET /api/v1/query_range`；连接串 `Mode=Range` 或 `range:` 前缀 |
| 指标名发现 | ✅ `GET /api/v1/label/__name__/values` |
| 写入 | ❌ 只读；不实现 remote write |
| 事务 / DDL / 自增 | ❌ |


> ✅ 支持；⚠️ 部分/条件支持；❌ 不支持。条件能力默认关闭，显式开启后再声明。
> 窗口函数列对应 `WindowFunctions`；标准 `ROWS/RANGE` 帧对应 `WindowFrame`，未单独列出。
> Firebird 已声明 `WindowFunctions`，但不声明 `WindowFrame`；KingBase/HighGo/VastBase/IRIS 静态声明窗口函数与窗口帧；DB2/达梦/HANA 在首次连接拿到服务器版本后按主版本追加（DB2 ≥ 9、达梦 ≥ 8、HANA ≥ 2），版本未知时保持保守。
> 不支持窗口函数的数据库可显式开启 `WindowFallback.InMemory`，由 `WindowEvaluator` 在结果集上计算窗口列。
> 实体写入：MongoDB、InfluxDB 与 OpenTSDB 通过 `IEntityPersistenceFactory` 使用原生适配器。InfluxDB 走 Line Protocol、OpenTSDB 走 JSON 数据点，都只支持追加写入；MongoDB 把实体映射为文档，需要应用侧注册 `IMongoDocumentWriter`（主包不引用 MongoDB.Driver）。
> 数组能力：PostgreSQL/VastBase 支持 `DatabaseCapability.Array`、一层强类型数组读写和建表/加列/改列 DDL；Presto/Trino 支持数组读写，DDL 仍由连接器负责。
