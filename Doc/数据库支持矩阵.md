# 数据库支持矩阵

> 版本：v12.3 | 日期：2026-11-20

本文档说明 XCode 对各数据库引擎的支持现状与落地成本。结论先行：**「有 ADO.NET 驱动」只是入场券，不等于 XCode 能直接支持**。

XCode 的提供者契约（`IDatabase` / `DbBase` / `DbMetaData`）还要求：

| 契约 | 说明 |
|------|------|
| `DbProviderFactory` | 能创建连接、命令、参数；部分驱动（如 Trino 官方 ADO）没有 |
| SQL 方言 | 标识符引用、分页、布尔/时间字面量、字符串拼接、关键字表 |
| 元数据 | `GetSchema` 或 `information_schema` 查询，否则反向工程与自动迁移不可用 |
| 事务 | 批量、迁移、`EntityTransaction` 依赖 |
| 自增/主键/索引 | XCode 实体模型默认假设存在自增主键 |
| 写入能力 | 增删改是否有意义，取决于引擎本身 |

## 二、B 档：协议兼容，零/低代码

只需在连接字符串中使用对应提供者名称，XCode 会落到 MySQL 或 PostgreSQL 提供者。当前已内置别名识别。

### MySQL 协议系（使用 `MySql` 提供者）

| 数据库 | 驱动 | 备注 |
|--------|------|------|
| MariaDB | NewLife.MySql / MySqlConnector | 已内置别名 `mariadb` |
| TiDB | NewLife.MySql / MySqlConnector | 别名 `tidb` |
| StarRocks | MySqlConnector / DotRocks（原生） | 别名 `starrocks`；原生 ADO 驱动为社区项目 |
| Apache Doris | MySqlConnector | 别名 `doris` |
| OceanBase（MySQL 模式） | MySqlConnector | 别名 `oceanbase` |
| SingleStore | MySqlConnector | 别名 `singlestore` |
| PolarDB / TDSQL / GoldenDB / GreatDB | MySqlConnector / 厂商驱动 | 别名已内置 |
| Databend | MySqlConnector（兼容 MySQL 协议） | 别名 `databend`，需核实版本差异 |

### PostgreSQL 协议系（使用 `PostgreSQL` 提供者）

| 数据库 | 驱动 | 备注 |
|--------|------|------|
| openGauss | Npgsql / OpenGauss.NET | 别名 `opengauss` |
| GaussDB | Npgsql / DotNetCore.GaussDB | 别名 `gaussdb` |
| Greenplum | Npgsql | 别名 `greenplum` |
| Amazon Redshift | Npgsql | 别名 `redshift`，部分 PostgreSQL 语法不支持 |

## 四、D 档：只有"读"是现实的

| 数据库 | 现实约束 |
|--------|---------|
| Presto / Trino | 读操作所有连接器可用；写操作与事务「大多数连接器不支持」（[Trino SQL support](https://trino.io/docs/current/language/sql-support.html)） |
| BigQuery / Athena / Hive / Impala | 无 OSS ADO.NET，只有 ODBC 或 CData 商业驱动 |
| ClickHouse | 已支持，但删除为异步、无强事务 |
| DuckDB | 已支持，单写者模型 |

---

## 五、E 档：不建议支持

| 数据库 | 原因 |
|--------|------|
| Redis / Elasticsearch / Kafka | 非关系型，没有可用的 OSS ADO.NET 驱动，且与 XCode 实体模型不匹配 |
| Cassandra / HBase | OSS 驱动不是 ADO.NET，只有 CData 商业驱动 |
| 各类 CData 商业驱动覆盖的引擎 | 收费、按引擎授权，不适合作为框架默认路径 |

## 六、Presto / Trino 能力边界

| 能力 | 支持情况 |
|------|---------|
| 查询 / 聚合 / 分页 | ✅ `OFFSET ... LIMIT ...` |
| 实体查询、反向工程 | ✅ 走 `information_schema.tables/columns` |
| Insert / Update / Delete | ⚠️ 取决于连接器，失败由服务端报错；实体主键不可声明为自增，否则抛出明确异常 |
| 事务 | ❌ 驱动与服务端均不支持 |
| 自增主键 | ❌ 无；请使用业务主键（Guid/雪花），或显式提供主键值并设置 `AllowInsertIdentity` |
| 自动建表 / 结构迁移 | ❌ 强制 `Migration=Off`，DDL 入口抛 `NotSupportedException` |
| 批量操作 | ❌ 不含 `DatabaseCapability.Bulk*` |
| 参数化 | ❌ 强制 `UseParameter=false`（NReco 使用 `{name}` 替换、Trino 使用 `?`，与 XCode 的 `@` 前缀不兼容） |
| 复杂类型（array/map/row/json） | ⚠️ 统一降级为字符串 |

### 连接字符串

**Presto（NReco.PrestoAdo）**

```
Host=localhost;Port=8080;Catalog=hive;Schema=default;User=test;Password=xxx
```

**Trino（Trino.Client.ADO）**

```
Host=localhost;Port=8080;EnableSSL=false;Catalog=hive;Schema=default;User=test
# Basic/LDAP/JWT 认证
Auth=BasicAuth;User=test;Password=xxx
Auth=TrinoJWTAuth;AccessToken=xxx
```

> `Database` 会被映射为 `Catalog`，`Owner` 会被映射为 `Schema`，兼容 XCode 的习惯写法。
> 官方 Trino 驱动默认 `EnableSSL=true`，XCode 在未显式指定时补 `EnableSSL=false` 与 `Port=8080`。

### 驱动说明

- Presto：`NReco.PrestoAdo 1.1.0`（netstandard2.0），无 `GetSchema`、`ExecuteNonQuery` 恒返回 1、2022 年后未更新。
- Trino：`Trino.Client.ADO 1.0.11`（netstandard2.0），官方代码由社区转发布，没有 `DbProviderFactory`，XCode 用反射工厂适配。

## 七、Firebird 能力边界

> 要求 Firebird 3.0+（IDENTITY 列与 `INSERT ... RETURNING`）。

| 能力 | 支持情况 |
|------|---------|
| 查询 / 分页 | ✅ `ROWS m TO n` |
| Insert / Update / Delete | ✅ |
| 自增主键 | ✅ `GENERATED BY DEFAULT AS IDENTITY`，插入使用 `INSERT ... RETURNING` |
| 事务 | ✅ |
| 自动建表 / 结构迁移 | ✅ 支持 Create Table / Add Column / 索引 |
| 窗口函数 | ✅ Firebird 3.0+ 支持 `OVER` 排名与聚合 |
| 窗口帧 | ❌ Firebird 3.0 不支持 `ROWS/RANGE` 帧 |
| 嵌入 / 远程 | ✅ 由连接字符串决定 |

```
Database=../data/test.fdb;DataSource=localhost;User=SYSDBA;Password=masterkey
```

## 八、其他新增数据库能力边界

| 数据库 | 标识符 | 名称折叠 | 分页 | 自增回读 | 自动迁移 | 元数据来源 |
|--------|--------|---------|------|---------|---------|-----------|
| Snowflake | `"..."` | 大写 | `LIMIT/OFFSET` | ❌（抛异常） | ✅ 基础建表 | `information_schema` |

| MonetDB | `"..."` | 小写 | `LIMIT/OFFSET` | ❌（抛异常） | ✅ 基础建表 | `sys.tables/sys.columns` |
| Spanner | `` `...` `` | 保留原样 | `LIMIT/OFFSET` | ❌（抛异常） | ❌ 强制关闭 | `information_schema` |

### 连接字符串示例

```
# Snowflake
account=xxx;user=xxx;password=xxx;db=TESTDB;schema=PUBLIC;warehouse=WH
# Vertica
Host=localhost;Port=5433;Database=test;User=xxx;Password=xxx;SearchPath=public
# SAP ASE
Data Source=localhost;Port=5000;Database=test;User ID=sa;Password=xxx
# Teradata
Data Source=localhost;User ID=xxx;Password=xxx;Database=test
# YashanDB
Data Source=localhost:1688;User ID=xxx;Password=xxx
# MonetDB
Host=localhost;Port=50000;Database=test;User=monetdb;Password=monetdb
# Spanner
Data Source=projects/p/instances/i/databases/d
```

> 除 ASE 与 Firebird 外，其余数据库都无法回读自增列；实体主键请使用业务主键（Guid/雪花），
> 或设置 `AllowInsertIdentity` 并显式赋值。

## 九、核实说明

- A 档状态以仓库代码与现有测试为准。
- B 档别名已在代码中生效，但除 MariaDB 外未逐一做真实服务互通测试。
- C 档驱动均于 2026-11 通过 NuGet 实测：能创建连接、命令、参数；Altibase/Exasol 因驱动或公开性不足未纳入。
- 新增提供者均已完成离线方言测试（标识符、布尔、时间、分页、连接串映射、能力开关），
  **未做真实服务互通测试**；上线前需按本文档的连接字符串示例补跑连通性与反向工程。
- D/E 档结论来自各引擎官方文档与驱动公开信息，标注了来源链接。

## 十、能力矩阵

> 能力模型已落地：`DatabaseProfile` + `DatabaseCapability` 成为代码事实源；下表用于快速对照，最终以代码声明为准。
> 全 Provider 的 `Profile`/能力声明一致性由 `DatabaseCapabilityTests.RegisteredProviders_HaveCapabilityProfile` 校验；本机 MySQL80 真库集成测试 29/29 通过；详细切片见 [M1-多数据库架构升级](M1-多数据库架构升级.md)。

| 数据库 | 模型/语言 | 事务 | 通用 DDL | 自增回读 | Update/Delete | Join | 批量 | 架构发现 | 窗口函数 |
|--------|-----------|:----:|:--------:|:--------:|:-------------:|:----:|:----:|:--------:|:--------:|
| SqlServer/MySql/PostgreSQL/Oracle/SQLite | 关系/SQL | ✅ | ✅ | ✅ | ✅ | ✅ | 各库不同 | ✅ | ✅ |
| DuckDB | 列式/SQL | ✅ | ✅ | ✅ | ✅ | ✅ | ❌ 批量未声明（可后续补实现） | ✅ | ✅ |
| ClickHouse | 列式/SQL | ❌ | ⚠️ | ❌ | ⚠️ mutation | ✅ | ❌ 批量未声明（可后续补实现） | ⚠️ | ✅ 仅函数，不声明帧 |
| MongoDB | 文档/原生命令 | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ 批量未声明（当前无实体 ORM） | ❌ | ❌ |
| InfluxDB | 时序/Flux | ❌ | ⚠️ | ❌ | ❌ | ❌ | Insert/Upsert（批量） | ⚠️ 仅 measurement | ❌ |
| TDengine | 时序/SQL | ❌ | ✅ | ❌ | ⚠️ | ⚠️ | Insert/Upsert | ❌ | ⚠️ |
| Presto/Trino | 联邦/SQL | ❌ | ❌ | ❌ | ⚠️ 连接器 | ✅ | ❌ | ✅ | ✅ |
| Spanner | 关系/SQL | ✅ | ⚠️ 强制关闭 | ❌ | ✅ | ✅ | ❌ | ✅ | ✅ |
| Snowflake/Vertica/Teradata/YashanDB/MonetDB | 数仓/SQL | ✅/⚠️ | ✅/⚠️ | ❌ | ✅ | ✅ | ❌ | ✅ | ✅/⚠️ |
| Network | 代理/SQL | ⚠️ | ❌ | 透传 | 透传 | 透传 | 委托服务端能力，移除本地 DDL | 透传 | 透传 |

> ✅ 支持；⚠️ 部分/条件支持；❌ 不支持。条件能力默认关闭，显式开启后再声明。
> 窗口函数列对应 `WindowFunctions`；标准 `ROWS/RANGE` 帧对应 `WindowFrame`，未单独列出。Firebird 已声明 `WindowFunctions`，但不声明 `WindowFrame`；DB2/达梦/Hana/IRIS/KingBase/HighGo/VastBase 暂未声明窗口能力，待版本检测或真库验证后逐个开启。
